# skill-creator

> Создание, проверка и улучшение навыков: каркас из шаблонов, сверка по чеклисту, разбор реального использования.

## Зачем это нужно

Этот навык помогает создавать навыки. Он собирает сам навык — инструкции,
скрипты-инструменты и порядок работы с ними — и окружение вокруг него:
README, AGENTS.md, тесты, CI.

- **Каркас по шаблону** — `create.php` разворачивает SKILL.md/README.md/AGENTS.md/CHANGELOG.md/LICENSE/CI/tests.
- **Общие правила** — что писать в SKILL.md (агенту-пользователю), что в README
  (человеку), что в `references/*` (методики и конвенции).
- **Проверка чеклистом** — ревизия навыков на соответствие.

## Что вы получите

После установки агент сможет:

- **создать навык** из идеи, документа, скрипта или работы в чате — развернёт
  каркас репозитория и заполнит его по правилам;
- **проверить SKILL.md** — сверит с чеклистом и скажет, как его лучше оформить;
- **улучшить навык** — соберёт наблюдения из истории сессий и отчётов, внесёт
  правки и оформит их: тесты, запись в CHANGELOG, версия и hash;
- **подготовить репозиторий навыка к публикации** — README.md, AGENTS.md, LICENSE, тесты и CI по шаблону.

Каркас — это черновик: агент дорабатывает его сам, тесты каркаса не пройдут, пока остались плейсхолдеры.

## Зависимости

PHP 8.4+. Без внешних зависимостей.

## Установка

Навык совместим с различными ИИ-агентами. Примеры ниже — для каталога
`.agents/skills`; для других инструментов смотрите их документацию по установке skills.

```bash
# Клон в каталог skills проекта
git clone https://github.com/prikotov/skill-creator.git .agents/skills/skill-creator

# Или симлинк на существующий клон (в любом проекте)
ln -s /path/to/skill-creator .agents/skills/skill-creator
```

## Использование

Навык работает через агента: после установки он узнаёт о навыке из каталога
`skills` и применяет, когда получает подходящий запрос. Примеры запросов:

```
Переведи .agents/skills/moex-site-core/SKILL.md на php и оформи
```

```
Проверь SKILL.md в cbr-core по чеклисту skill-creator и скажи, что перенести в references
```

```
Разбери, как skill работал в реальных сессиях, и предложи улучшения
```

Что делает агент по такому запросу: разворачивает каркас командой
`php <skills-dir>/skill-creator/scripts/create.php --name <name> --dir <path>`,
где `<skills-dir>` — каталог skills вашего инструмента (в примерах установки
выше — `.agents/skills`). Дальше агент заполняет плейсхолдеры по правилам
SKILL.md, доводит `tests/run.php` каркаса до зелёного, оформляет репозиторий
к публикации. Параметры `create.php` — в SKILL.md, раздел «Каркас: create.php».

## Конфиг и секреты

Секретов навык не требует.

## Как устроено

- Шаблоны в `assets/` с плейсхолдерами `{{…}}`; `create.php` подставляет
  известные (name, title, скрипты, клиент) и возвращает оставшиеся —
  их заполняет агент по правилам из SKILL.md.
- Сгенерированный каркас сразу проходит `php -l`; `tests/run.php` падает,
  пока не заполнены плейсхолдеры.

## Правила

- SKILL.md — агенту-пользователю; README — человеку; `references/` — методики
  и конвенции. Не смешивать.
- Пример запроса агенту — только реальный из истории сессии.
- Новые правила навыков добавлять в SKILL.md этого репозитория, а не плодить
  частные инструкции в проектах.
