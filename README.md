# Skill Creator

> Создание skill: каркас репо из шаблонов и проверка чеклистом.

Это **skill для AI-агентов** (формат SKILL.md): репо подключается в каталог
skills проекта (`.agents/skills` и аналоги), агент читает `SKILL.md` и сам
разворачивает каркас нового скилла и заполняет его по правилам.
Человек может запустить скрипт вручную — см. «Использование».
`SKILL.md` — инструкция агента (правила скиллов, чеклист, примеры); этот
README — установка, устройство и справочник.

## Зачем это нужно

SKILL.md этого репо — инструкция по созданию навыков: структура скилла,
frontmatter, разделы, формат шага, чеклист. На практике к ней добавились
правила «что в какой раздел и что не в SKILL.md», скрипты с JSON-контрактом
и оформление репо (web-research-fallback, moex-site-core, cbr-core прошли
этот путь). Скрипт `new.php` разворачивает каркас по этим правилам.

- **Каркас за секунду** — `new.php` разворачивает SKILL/README/AGENTS/LICENSE/
  CI/tests, а если указаны скрипты — общий клиент и по заготовке на скрипт.
- **Единые правила** — что писать в SKILL.md (навык для модели), что в README
  (устройство для человека), что в `references/` (механика).
- **Проверка чеклистом** — ревизия старых и чужих скиллов на соответствие.

## Что вы получите

| Файл | Что делает |
|------|------------|
| `SKILL.md` | Правила скиллов, чеклист проверки, опции `new.php` |
| `scripts/new.php` | Разворачивает каркас репо скилла из шаблонов; скрипты — по `--script`, 0 или много |
| `assets/*.template.*` | Шаблоны SKILL.md, README.md, AGENTS.md, CI |
| `references/rules.md` | Что взято из инструкции по созданию SKILL, что добавлено практикой; таблица «SKILL или README» |

## Зависимости

PHP 8.4+ (ext-curl нужен только сгенерированному каркасу). Без composer.

## Установка

Skill совместим с различными AI-агентами. Примеры ниже — для каталога
`.agents/skills`; для других инструментов смотрите их документацию по установке skills.

```bash
# Клон в каталог skills проекта
git clone https://github.com/prikotov/skill-creator.git .agents/skills/skill-creator

# Или симлинк на существующий клон (в любом проекте)
ln -s /path/to/skill-creator .agents/skills/skill-creator
```

## Использование

Команды ниже — от каталога с SKILL.md: из корня репо скилла или от каталога,
куда он установлен в проект.

### new.php — каркас нового скилла

```bash
# Скилл-инструкция без скриптов
php scripts/new.php --name prompt-review

# Скилл с двумя скриптами
php scripts/new.php --name moex-site-core --script map --script search

# Явный каталог, заголовок, описание для модели
php scripts/new.php --name cbr-core --dir /home/dp/MyProjects/cbr-core \
  --title "CBR Core" --description "Сайт и API ЦБ: карта, поиск, ОРФР" --script orfr
```

#### Параметры new.php

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `--name` | Имя скилла, kebab-case (обязательно) | — |
| `--dir` | Каталог репо | `~/MyProjects/<name>` |
| `--title` | Заголовок `# …` | Name Case из name |
| `--description` | Описание скилла для модели (frontmatter) | заглушка |
| `--license` | Лицензия: `MIT` (файл LICENSE) или `none` | `MIT` |

#### Результаты new.php

- stdout — JSON: `ok`, `dir`, `scripts[]`, `files[]`, `placeholders_left`
  (по файлам), `next[]` — что делать дальше.
- Существующий непустой каталог не трогается: код выхода 1.
- `git init`, коммит и создание репо на GitHub скрипт не делает — это шаги
  из `next[]`.

### Через агента

После установки skill агент автоматически узнаёт о нём. Примеры запросов:

```
Переведи .agents/skills/moex-site-core/SKILL.md на php и оформи
```

```
Проверь SKILL.md в cbr-core по чеклисту skill-creator и скажи, что перенести в references
```

## Конфиг и секреты

Секретов скилл не требует.

## Как устроено

- Шаблоны в `assets/` с плейсхолдерами `{{…}}`; `new.php` подставляет
  известные (name, title, скрипты, клиент) и возвращает оставшиеся —
  их заполняет агент по правилам из SKILL.md.
- Сгенерированный каркас сразу проходит `php -l` и `tests/run.php` —
  заготовки клиента и тестов рабочие, не пустышки.
- Стандарт — [references/rules.md](references/rules.md).

## Правила

- SKILL.md — навык для модели; README — устройство для человека; `references/`
  — механика. Не смешивать.
- Пример запроса агенту — только реальный из истории сессии.
- Новые правила скиллов добавлять в SKILL.md этого репо, а не плодить
  частные инструкции в проектах.

Подробнее — [SKILL.md](SKILL.md), основа и дополнения — [references/rules.md](references/rules.md).
