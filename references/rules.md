# От SKILL-CREATION.md к skill-creator

Основа — `TInvestSkills/docs/SKILL-CREATION.md` (инструкция по созданию
навыков). Skill-creator переносит её в skill и дополняет тем, что накопилось
в web-research-fallback, moex-site-core, cbr-core.

## Что взято из SKILL-CREATION.md без изменений

- SKILL — переносимый модуль (инструкции + скрипты), который агент загружает
  по мере необходимости.
- Структура папки: `SKILL.md` (обязателен), `scripts/`, `references/`, `assets/`.
- Frontmatter: `name` kebab-case, `description` (до 1024 символов, без
  XML-тегов).
- Тело SKILL.md: **Когда использовать → Как использовать → Результат**.
- Шаг: инструкция + команда + таблица опций (опция / описание / значения /
  по умолчанию) + примеры.
- Результат: что и где получим; таблица полей.
- Чеклист из документа — включён в чеклист SKILL.md skill-creator.

## Что добавлено практикой

Добавления не меняют структуру документа, а уточняют, **что** писать в
каждый раздел и что в SKILL.md не писать.

- **Раздел «Правила агента»** — четвертый обязательный раздел: запреты,
  границы, поведение в спорных случаях. В исходной инструкции его не было;
  без него агент угадывает (пример: «сниппеты — только для выбора URL»).
- **Адресаты документации**: SKILL.md — агенту-пользователю, README —
  человеку, AGENTS.md — агенту, разрабатывающему репо. Дублирование — ошибка.
- **Что не в SKILL.md**: требования к бинарнику, устройство клиента, порядок
  способов, ключи — это README; справочные факты о среде — `references/`.
  SKILL.md отвечает на «когда и как применять», README — «как устроено».
- **description — «когда использовать»**, не пересказ содержания: агент
  выбирает скилл по description.
- **stdout — JSON-контракт, stderr — прогресс, код выхода 0/1**: агент
  парсит результат, а не читает простыню.
- **PHP 8.4+, ext-curl, без composer** — стек владельца; Python-скиллы
  мигрируют (moex-site-core переведён 2026-11-25).
- **Ловушки переезда на PHP**: PDO автокоммитит на строку — массовая запись
  только в транзакции; `WHERE LOWER(col)` без индекса — полный скан на
  каждый апсерт.
- **Оформление репа** (образец `prikotov/knowledge-extraction`): LICENSE MIT,
  AGENTS.md, `tests/run.php` + CI (`php -l` + тесты), README с разделами
  «Конфиг и секреты» и «Лицензия»; description на GitHub начинается со
  «Skill для AI-агентов», branch protection `main`.
- **Пример запроса агенту — только реальный**, дословно из истории сессии.
- **Язык**: один термин — одно слово; короткие предложения, активный залог;
  термин раскрывать при первом упоминании; без лозунгов и дублей.

## Чеклист «SKILL.md или README?»

| Факт | Куда |
|------|------|
| Когда применять скилл | SKILL.md (description + раздел) |
| Опции скрипта, значения по умолчанию | SKILL.md |
| Поля JSON-результата | SKILL.md |
| Запреты и границы для агента | SKILL.md, «Правила агента» |
| Как установить скилл | README |
| Из чего состоит клиент, порядок способов | README, «Как устроено» |
| Ключи и конфиг | README, «Конфиг и секреты» |
| Поведение сайтов/API, ловушки, отрицательные результаты | `references/` |
| Правила разработки репо, контракты вывода | AGENTS.md |
| Тестовые запросы и пробы владельца | никуда (не пишутся) |
