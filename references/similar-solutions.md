# Похожие решения: мониторинг и заимствование

Файл — реестр чужих решений в нише «создание навыков для ИИ-агентов».
Задача: следить за развитием, заимствовать проверенные фичи, не терять
свои отличия. Обновлять при новом релизе аналога или раз в квартал.
Правки сюда — через «Улучшение»: наблюдение → правка → тестирование.

## Аналоги: суть подхода

### skill-creator (Anthropic)

Eval-платформа, а не методика. Цикл: черновик → тест-промпты → параллельные
прогоны с навыком и без (baseline) → утверждения (assertions) → grader →
benchmark.json (pass rate, время, токены, ± разброс) → HTML-viewer для
человека → правки → повтор. Отдельный контур: оптимизация `description` —
20 trigger-запросов (should/should-not, негативы «на грани»), 60/40
train/test, прогон каждого запроса 3 раза, автопереписывание до 5 итераций,
выбор по test-скорости. Субагенты: grader, comparator (слепое A/B), analyzer
(неселективные утверждения, высокая дисперсия). Идеи уровня текста:
«объясняй why вместо MUST», «скрипт, который тестовые прогоны пишут трижды,
заслуживает места в scripts/».

### writing-skills (superpowers)

TDD, применённый к документации процессов. Iron Law: «нет навыка без
падающего теста» — действует и на правки. RED: прогон сценария без навыка,
дословная фиксация рационализаций агента. GREEN: минимальный навык под
зафиксированные провалы. REFACTOR: закрытие лазеек до пуленепробиваемости.
Ключевая идея — «форма следует за провалом»: запрет лечит нарушение
дисциплины, рецепт/контракт лечит неверную форму результата, структурное
поле лечит пропуск элемента, условие лечит безусловность. Формулировки
микротестируют: контроль без наставления, 5+ повторов, ручное чтение
совпадений, дисперсия как метрика. Таблица рационализаций и red-flags —
обязательные части дисциплинарных навыков.

### SkillForge v6

Pipeline из гейтов: TRIAGE (роутинг запроса: use/improve/create/compose/
clarify) → RED GATE (фреш-субагент без навыка; нет провала — нет навыка) →
SPEC → GENERATE (фреш-субагент получает только спецификацию и baseline
провалы) → GREEN GATE (с навыком провалы закрыты + trigger-тесты) → REVIEW
(lint + один adversarial-рецензент, задача которого опровергнуть) → SHIP.
Навык выходит с собственным `evals/` — регрессионным сьютом. Doctor для
экосистемы: коллизии триггеров, дубликаты, мёртвые ссылки, перерасход
бюджета. Кросс-рантайм-компиляция (claude/codex/agentskills). Friction
mining — поиск пробелов навыков по собственной истории сессий (opt-in).
Девиз: «качество навыка — свойство поведения, не документа». Урок их аудита
v5→v6: краткий SKILL.md, глубина в references; панель единогласия хуже
одного оппонента; self-scored одобрение без внешнего доказательства не
работает.

## Заимствовать: кандидаты по приоритету

1. **Baseline «без навыка» в «Тестирование»** (superpowers, SkillForge,
   Anthropic). Наш тест проверяет «агент справился с навыком», но не
   доказывает, что навык изменил поведение. Добавить к типовой задаче
   прогон-контроль без навыка; польза без навыка = критерий «навык нужен».
2. **Trigger-тесты description** (Anthropic, SkillForge). Список запросов
   should/should-not-trigger, негативы «на грани»; сверять routing руками
   в свежих сессиях — дешевле автолупа, ловит undertrigger.
3. **«Форма следует за провалу»** (superpowers) — таблицу из четырёх пар
   «провал → форма» в «Форму навыка»: запрет против дисциплины, рецепт
   против кривой формы, структурное поле против пропусков, условие против
   безусловности. Наша «Форма» описывает структуру, но не выбор формы
   наставления.
4. **Один adversarial-рецензент** (SkillForge) — при проверке навыка
   назначать одного рецензента с задачей опровергнуть, вместо размытого
   «проверь». Уже близко нашей роли скептика; формализовать.
5. **evals/ у сложных навыков** (SkillForge) — регрессионный набор задач
   рядом с навыком для сложных случаев; наш чеклист не версионирует задачи.
6. **Doctor для семьи навыков** (SkillForge) — раз в квартал: коллизии
   description, мёртвые ссылки, дубликаты по нашим навыкам.

## Не заимствовать (пока)

- HTML-viewer и бенчмарк с токенами — тяжёлая инфраструктура, у нас ручной
  надзор дешевле; вернуться при серийном создании навыков.
- Автолуп оптимизации description через API — стоимость прогонов; ручные
  trigger-тесты дают 80% пользы.
- Панели согласования агентов — SkillForge сам отказался после аудита.
- Кросс-рантайм-компиляция — пока наши навыки живут в pi.
