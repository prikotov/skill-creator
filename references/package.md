# package — источник и состояние навыка

## Что это

`package` — необязательное поле YAML-frontmatter SKILL.md: URL
репозитория-источника навыка. Состояние копии описывают поля `version`,
`updated` и `hash`. Собственное расширение поверх стандарта Agent Skills.
Нет `package` — навык локальный: улучшают его на месте, PR некуда отправлять.

## Поля

```yaml
package: https://github.com/user/prompt-review
version: 1.1.0
updated: 2026-11-27 14:30 UTC
hash: 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08
```

- `url` — репозиторий глобального навыка.
- `version` — версия: внешняя (тег источника) либо локальная (присваивает агент).
- `updated` — дата и время последней правки, `YYYY-MM-DD HH:MM UTC`.
- `hash` — отпечаток содержимого копии; по нему проверяют, что копия не
  правилась в обход источника.

## Подсчёт hash

hash — sha256 по файлам навыка; имена файлов сортируют, содержимое склеивают.
Строки `hash:` во всех файлах навыка при подсчёте заменяют на фиксированную соль
`hash: package` — иначе подсчёт невозможен: любое значение в самой строке
меняет результат, а hash пишется и в SKILL.md, и в записи CHANGELOG.
Соль одна для всех навыков. Каталоги `.git/` и `data/`
в подсчёт не входят.

Процедура — один скрипт skill-creator; `<skill-creator>` — каталог его SKILL.md:

```bash
php <skill-creator>/scripts/hash.php <каталог-навыка>           # напечатать hash
php <skill-creator>/scripts/hash.php --write <каталог-навыка>   # вписать в SKILL.md
```

Проверка копии: повтори подсчёт и сравни с записанным. Совпал — содержимое
не менялось. Разошёлся — копия правилась вне порядка улучшения.

## CHANGELOG.md

История улучшений в корне навыка. Запись на каждое улучшение:

```markdown
## 1.1.0 — 2026-11-27 14:30 UTC

hash: 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

- Проблема: агент пропускал проверку лицензии в frontmatter.
- Решение: Evaluate начинается с чеклиста frontmatter.
- PR: #12 — для глобального навыка; у локального пункта нет.
```

hash в записи связывает изменение с состоянием файлов: по hash копии находят
нужную запись. Версия, отметка времени и hash верхней записи совпадают с полями
`version`, `updated`, `hash` в SKILL.md.

## Оформление улучшения

1. Правь файлы навыка.
2. Запиши в CHANGELOG.md: проблема, решение, PR.
3. Подними `version`, поставь `updated`, пересчитай `hash` скриптом
   `scripts/hash.php --write`.
4. Глобальный навык — отправь PR в репозиторий из `package`.
5. После мержа синхронизируй копии и пересчитай `hash`.
