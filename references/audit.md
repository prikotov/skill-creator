# Разбор истории сессий

Готовишь улучшение навыка или просили проверить, как навык работал на реальных
задачах. Источник — сессии pi, где навык упоминался. Результат — отчёт
по конвенции `reports.md` с наблюдениями для Evolve.

## Шаги

1. Найди сессии, где работал навык.
2. Разбери хронологию выбранных сессий.
3. Классифицируй наблюдения — `harvest.md`.
4. Запиши отчёт — `reports.md`.

## Как читать сессию

Логи сессий pi: `~/.pi/agent/sessions/` — jsonl, по одному событию на строку.
Ищи по имени навыка или по ключевым словам темы; навык ещё не работал, имени
в истории нет — ищи по ключевым словам.

Из потока событий бери только нужное для анализа.

## Правила

- Сессии и файлы проверяемого навыка только читаются.
- Аргументы вызовов инструментов в разбор и отчёт не выводи: в них бывают
  секреты (токены, ключи).
- Секреты из сессий (токены, ключи) в отчёты не переноси.
- Отсутствующие в сессии данные не восполняй предположениями — фиксируй
  неопределённость (принцип `harvest.md`).
