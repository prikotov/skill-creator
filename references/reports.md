# Отчёты о работе

## Что это

Наблюдения за проверками навыка: тестирование при создании и после правок,
разбор истории сессий. Хранятся в проекте, где навык работал: `<skills-dir>/_reports/<name>/` —
общий каталог проекта, подкаталог на навык. Путь считай от места установки,
симлинк не разворачивай. Репозиторий навыка отчёты не содержит — только
CHANGELOG с решениями.

## Когда создаётся

Каждое выполнение навыка отчётом не сопровождается — это лишние токены и
засорение контекста. Отчёт пишет агент по прямой просьбе пользователя или по
триггеру «Проверки в работе»: один разбор — один файл; разбор — по
`audit.md`.

## Создание

1. Создай каталог: `<skills-dir>/_reports/<name>/`.
2. Собери шапку и тело. Шапка — четыре строки: Навык, Дата, Сессии, Задача.
   Тело — самодостаточное: что ожидали, что вышло, наблюдения с причинами;
   методика — `harvest.md`.
3. Сохрани файл: `<name>-YYYY-MM-DD_HH-MM-SS.md` (время по UTC).
4. Выведи пользователю краткое резюме и путь к файлу.

Форма шапки:

```markdown
**Навык:** <name> <версия>
**Дата:** YYYY-MM-DD
**Сессии:** <id или пути файлов сессий>
**Задача:** <что проверялось: выполнение, анализ истории>
```

Проекты, где навык работал, видны по cwd из истории сессий.
