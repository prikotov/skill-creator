# depends_on — зависимость навыка от другого навыка

## Что это

`depends_on` — необязательное поле YAML-frontmatter SKILL.md: список навыков,
необходимых для работы этого навыка. Собственное расширение поверх стандарта
Agent Skills: в спецификации поля нет.

## Формат

- YAML-список имён; каждое совпадает с `name:` зависимого SKILL.md.
- Порядок не важен; дублей не оставлять.
- Пустой список эквивалентен отсутствию поля.

## Семантика

Зависимость означает: навык при работе вызывает перечисленный навык, и без
него задача может не решиться. Недоступная зависимость — стоп до старта, вопрос пользователю.
Как именно выполнять вызов — решает агент в контексте проекта.
