# AGENTS.md — для ИИ-агентов, разрабатывающих этот репозиторий

## Что это за проект

**skill-creator** — agent-skill: создание скиллов по стандарту владельца.
`scripts/new.php` разворачивает каркас репо из шаблонов `assets/`; SKILL.md —
правила заполнения каркаса и чеклист проверки. PHP 8.4+, без composer.

Документация по адресатам: `SKILL.md` — инструкции для агентов-пользователей
(правила скиллов), `README.md` — для людей, этот файл — для разработки.
Источники стандарта и что из них взято — `references/rules.md`.

## Архитектура

```
scripts/new.php      — каркас: подстановка плейсхолдеров, заготовки клиента/скрипта/тестов
assets/*.template.*  — SKILL.md, README.md, AGENTS.md, CI (плейсхолдеры {{…}})
references/rules.md  — основа SKILL-CREATION.md, что добавлено практикой, таблица «SKILL или README»
tests/run.php        — каркас во временном каталоге: файлы, php -l, тесты каркаса
```

**Контракт вывода `new.php`** (stdout, машиночитаемый, не ломать):
`ok, dir, files[], placeholders_left{плейсхолдер: [файлы]}, next[]`.
Ошибки — в stderr, код выхода 1 (имя не kebab-case, каталог не пуст).

## Правила разработки

- Шаблоны и правила меняются вместе: новое правило в SKILL.md должно иметь
  отражение в шаблонах (или явное «не в SKILL.md»).
- Сгенерированный каркас обязан сразу проходить `php -l` и свои
  `tests/run.php` — тест `tests/run.php` этого репо это проверяет.
- Скрипт не делает `git init`, коммиты и GitHub-операции — только файлы.
- Офлайн-тесты и `php -l` — до коммита; CI гоняет их на каждый push/PR.
