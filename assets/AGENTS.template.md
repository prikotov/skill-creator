# AGENTS.md — для ИИ-агентов, разрабатывающих этот репозиторий

## Что это за проект

**{{name}}** — навык для ИИ-агентов: {{what-skill}}.

Назначение файлов:

- `SKILL.md` — агенту-пользователю: когда применять, как действовать, что получится.
- `README.md` — человеку: зачем навык нужен, как установить и настроить.
- `AGENTS.md` — агенту-разработчику: архитектура, контракты вывода, правила разработки.
- `CHANGELOG.md` — история улучшений: проблема → решение → PR.

Навык устанавливается в рабочие проекты (симлинком или git-клоном). После
коммита синхронизируй установленные git-клоны (`git pull --ff-only`); симлинки
обновляются сами.

## Архитектура

```
scripts/                 — скрипты навыка; добавляй по мере надобности
tests/                   — тесты зеркально исходникам: scripts/, docs/; run.php — раннер
.github/workflows/ci.yml — CI: `php -l` + `php tests/run.php` на каждый push/PR
```

Контракт вывода скриптов: результат — JSON в stdout; прогресс, предупреждения
и ошибки — в stderr; код выхода 0/1.

## Правила разработки

- {{dev-rule}}
- PHP 8.4+; composer — только когда без него не решить.
- Для каждого скрипта — тест зеркально пути: `scripts/x.php` → `tests/scripts/x.php`;
  зарегистрируй его в `tests/run.php`: fixture-вход → ожидаемый код выхода
  и формат вывода.
- Приёмы тестов — в AGENTS.md skill-creator.
- Офлайн-тесты (`php tests/run.php`) и `php -l` должны проходить до коммита;
  CI запускает их на каждый push/PR.
